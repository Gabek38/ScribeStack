# ScribeStack API Reference

## Authentication

All requests require a Bearer token
in the Authorization header:

```http
GET /v1/endpoint HTTP/1.1
Authorization: Bearer <token>
```

## Response Format

```json
{
  "status": "success",
  "data": { ... },
  "meta": {
    "version": "1.0.2"
  }
}
```
